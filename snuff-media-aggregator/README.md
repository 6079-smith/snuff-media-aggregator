# Snuff Tobacco Media Aggregator

A web-based application that aggregates and displays online content related to snuff tobacco, including forums, YouTube channels, online stores, manufacturers, and informational resources.

## Features

- **Resource Directory**: Curated collection of snuff tobacco websites categorized by type
- **Search Functionality**: Easily search through all resources
- **Filtering System**: Filter resources by category (forums, YouTube, stores, etc.)
- **Responsive Design**: Optimized for both desktop and mobile devices

## Getting Started

1. Clone this repository
2. Open `index.html` in your browser
3. Use the search and filter functions to find relevant snuff tobacco resources

## Project Structure

- `index.html` - Main webpage with resource listings
- `styles.css` - Styling for the webpage
- `script.js` - JavaScript for search and filter functionality
